# 用途プロファイル: ビジネスチャット（chat / chat_external）

Slack、Teams、Chatworkなどで送るメッセージ、チャンネルへのお知らせ、スレッドへの返信に使います。社内向けは`chat`、取引先など社外向けは`chat_external`です。リンターは`--profile chat`または`--profile chat_external`で検査します。

---

## 1. 文体

- 「です・ます」で書きます。社内向けは軽めにし、「いたします」「〜のほどよろしくお願いいたします」は「します」「お願いします」にします。社外向けは敬語の段階を下げません。
- 1行目に要件（報告、依頼、結論）を書きます。挨拶の行は数えず、挨拶を付けるときはその次の行に要件を書きます。
- 「お疲れ様です」は、元の文にあるときか、書き手の実例やボイスカードで使っているときだけ付けます。それ以外では足しません。スレッド内の返信では付けません。
- 数量は算用数字で書きます（「三回」→「3回」）。
- 1文は15〜35字を目安にします。
- 主語は初めて出たところで書き、同じ主語が続く文では省きます。送り手が誰かはチャットの表示で分かるので、「インフラチームは〜します」を何度も書きません。
- 依頼には、相手と期限を書きます。元の文に書かれていない相手や期限は足さず、「書き手に確かめたい点」に出します。

## 2. 構造と記号

- 並列の情報（日時、対象、お願いごと）は箇条書きのまま残し、地の文にまとめません。SKILL.mdの「箇条書きを地の文に統合する」決まりより、こちらを優先します。
- 「日時：10月4日（日）2:00〜6:00」のようなラベル付きの行は使ってかまいません。整えるときも、地の文に並んだ並列の情報は、順番を変えずにこの形にしてかまいません。
- 箇条書きの行末の句点は、付けるか付けないかを1つのメッセージの中でそろえます。
- 箇条書きの前の「お願いが3点あります」のような件数を伝える導入は、読み手が量を見積もれるので残します。中身のない「以下の通りです」だけを削ります。
- 絵文字は、社内向けなら意味を補うもの（🙏 🙇 👀 👍 🙌 🎉）を1メッセージに1個までにします。社外向けでは使いません。
- Markdownの太字（**）は表示されない環境が多いので、強調は【】や1行目に置くことで示します。
- 「！」は社内向けで1回までにします。社外向けでは使いません。

## 3. 硬さ

- 硬さ辞書（`references/humanize/stiffness.md`）は、社内向けは強さ3、社外向けは強さ2で使います。

## 4. 足してよい定型

チャットの定型は内容の追加とは別に扱い、次のものは足してかまいません。

- 冒頭の「お疲れ様です」1行（社内向けで、書き手の実例やボイスカードで使っている場合のみ）
- 宛先のメンション（元の文に宛先が書かれている場合）
- 最後の「気になる点があればこのスレッドでお願いします」のような返信先の一言

期限、担当者、数値のような事実は、定型であっても足しません。

## 5. この用途に特有のAIっぽさ

`references/humanize/humanize-slop.md`の7に加えて、次のものがあります。

- 1つのメッセージに見出し（「## 概要」）を付ける
- 箇条書きの各項目を太字のラベルで始める
- 「お忙しいところ恐縮ですが」「ご確認のほどよろしくお願いいたします」を重ねる
- 箇条書きで送れば済むお知らせを、長い地の文にまとめる
