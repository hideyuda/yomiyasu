# ボイスカード

書き手の文章の癖をまとめるカードです。yomiyasuは、書き分けるときや人間らしさを足すときに、このカードの内容を用途プロファイルの一般的な決まりより優先します。分からない項目は空欄のままでかまいません。

- 一人称: （私 / 僕 / 自分 / 書かない）
- 文末: （です・ます中心 / 常体 / 混在。よく使う形の例: 〜ですね、〜かも、〜と思います）
- よく使うつなぎ言葉: （例: なので、ただ、とはいえ）
- 使わない言葉: （例: 〜させていただきます、ぶっちゃけ）
- 絵文字: （使わない / 🙏だけ使う / 投稿ごとに1個まで）
- 感嘆符「！」: （使わない / 1回まで / よく使う）
- 句読点と改行: （「、。」 / 「，．」 / 文ごとに改行する）
- 1文の長さ: （短め / 標準 / 長め）
- 用途ごとのメモ: （例: Slackでは結論を1行目に書く。Xでは常体で、ハッシュタグは付けない）
