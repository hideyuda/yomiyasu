# 人間らしさスロップ（人が書いたように見せようとして出る癖）

LLMに「人間らしく」「もっとカジュアルに」と指示すると、AIっぽさが消える代わりに別の決まった癖が出る。口語の盛りすぎ、根拠のない感嘆符、作り話の体験談などで、読み手はすぐに「AIが人のふりをしている」と気づく。

本カタログはこうした癖をまとめたものである。用途ごとに使ってよい回数の上限を決め、リンター（`yomiyasu_lint.py --profile`）で数える。上限は`scripts/profiles.json`の`humanize_slop`に書いてあり、書いていない項目の上限は0回である。

書き手のボイスカード（SKILL.md「書き手の実例とボイスカード」）に、書き手がふだん使う言い方として載っているものは、この上限より書き手の癖を優先する。たとえば書き手が「！」をよく使う人なら、「！」を消さない。リンターの上限は、`--profiles-file`で自分用のプロファイルを作って変える。

---

## 1. 口語の盛りすぎ

| 表現 | 問題 | 方針 |
|---|---|---|
| 正直、 / 正直に言うと | 正直さを宣言しても内容は変わらない | 削る。元の文にある場合も、評価を担っていなければ削る |
| ぶっちゃけ / マジで / ガチで | 書き手の口癖でない限り、演出に見える | 元の文かボイスカードにある場合だけ使う |
| 〜なんですよね | 1回なら自然だが、続くと馴れ馴れしい | 記事とSNSで1文書に1回まで |
| 〜じゃないですか | 読み手に同意を求める押しつけ | 使わない |
| 〜って感じです / 〜的な | ぼかしの演出 | 使わない |

## 2. 感情の水増し

| 表現 | 問題 | 方針 |
|---|---|---|
| 「！」の連発 | 2回目からは温度が上がらず、宣伝文に見える | 記事、SNS、社内チャットで1文書に1回まで。資料と社外チャットでは使わない |
| 笑 / w / （笑） | 書き手の癖でない限り、無理に崩した印象になる | ボイスカードにある場合だけ使う |
| 最高 / 神 / 爆速 / 〜すぎる | 元の文にない誇張 | 元の文にある評価だけを書く |

## 3. 作り話（情報の増補）

人間らしさを出そうとして、元の文にない体験や感想や数字を足してしまう。SKILL.md「情報の不増補」に反するため、どの用途でも禁止する。

- 「先日、私も〜しました」「実際に使ってみて〜と感じました」のような体験談
- 「多くの人が〜で悩んでいます」のような根拠のない一般化
- 「作業時間が3倍速くなった」のような元の文にない数字
- 元の文にない固有名詞（店名、製品名、人名）

書き手の体験や意見が入ると読みやすくなる場所でも、本文を作らない。整えるときは本文に空欄を入れず、出力の「書き手に埋めてほしいところ」に、どこに何を足すと読みやすくなるかを提案する。書き分けるときは`[ここに一言]`のような空欄を本文に入れてもよい（必須ではない）。空欄は1つの文章に2か所まで（チャットは1か所、資料は0か所）とする。

## 4. 読み手に寄りかかる問いかけと呼びかけ

| 表現 | 問題 | 方針 |
|---|---|---|
| 〜ではないでしょうか | 言い切れることを問いの形にする修辞疑問 | 元の文の強さで書く（断定なら断定、推量なら「〜と思います」） |
| 〜で困っていませんか | 広告の書き出し | 使わない |
| みなさん、こんにちは | 定型の挨拶 | 使わない |
| 〜していきましょう！ | 定型の呼びかけ | 使わない |

## 5. 「実は」系の前置き

| 表現 | 問題 | 方針 |
|---|---|---|
| 実は / 意外と / ちなみに / ここだけの話 | 驚きや補足がないところで使うと、話し言葉らしさの演出になる | 1文書に1回まで。驚きや補足の中身がある場合だけ使う |

## 6. SNSの定型

| 表現 | 問題 | 方針 |
|---|---|---|
| 【保存版】【必見】【朗報】 | 煽りの見出し | 使わない |
| 〜な件 / 〜してみた | 定型のタイトル | 元の文のタイトルでない限り使わない |
| 👇 / 🧵 / スレッドで解説 | スレッドへの誘導 | 実際に投稿を分けるときだけ使う |
| ハッシュタグ3つ以上 | 宣伝に見える | 0〜2個 |
| 項目ごとの絵文字（✅ 📌 💡） | 装飾で盛る | 絵文字は1投稿に2個まで |
| いいね・リポストのお願い | 定型の締め | 元の文にない限り書かない |

## 7. ビジネスチャットの定型

| 表現 | 問題 | 方針 |
|---|---|---|
| 元の文にない「お疲れ様です」を足す、スレッド内の返信でも毎回付ける | 要件が後ろに押し出される | 元の文にあるか、書き手の実例やボイスカードで使っている場合だけ付ける |
| 「お忙しいところ恐縮ですが、〜の件でご連絡いたしました」 | 前置きが長い | 1行目に要件を書く |
| 「以下の通りです」「下記をご確認ください」 | 予告だけの文 | 削って本題から書く。「お願いが3点あります」のように件数を伝える導入は残す |
| 「承知いたしました」で毎回始める | 判で押した返事に見える | 返事の中身から書く。社外向けでは1回だけ残す |
