# 書き手の実例（exemplars）とボイスカード

yomiyasuは、書き手が自分で書いた文章（実例）とボイスカードがあれば読み、用途プロファイルの一般的な決まりより優先します。人が書いた文章を2〜3本置くだけで、文末、文の長さ、記号の使い方、口語の量がその人の書き方に近づきます。

## 置き場所

1がいちばん優先です。スキルを更新しても消えないよう、自分の実例は1か2に置くことをおすすめします。

1. 作業中のプロジェクト直下の`.yomiyasu/`
2. ホームディレクトリの`~/.yomiyasu/`
3. スキル同梱の`references/exemplars/`（このフォルダ）

```text
.yomiyasu/
├── voice-card.md            # ボイスカード（下のテンプレートから作る）
└── exemplars/
    ├── proposal/            # 通った提案書やスライドの本文
    ├── article/             # 公開した記事
    ├── sns/                 # 自分の投稿
    └── chat/                # 自分が送ったSlackなどのメッセージ
```

## 実例の決まり

- 書き手本人（またはチーム）が書いた文章だけを置きます。AIが書いた文章や、AIが書き直した文章は置きません。AIの文章を手本にすると、AIの癖をそのまままねてしまいます。
- 1ファイルに1本、200〜800字程度が目安です。チャットは1ファイルに数メッセージまとめてかまいません。
- 社外秘の情報や個人名は、伏せてから置きます。
- yomiyasuは実例を、書き方（文末、長さ、記号、口語の量）を合わせるための参考にだけ使い、内容や言い回しをそのまま写しません。

## ボイスカード

`voice-card.template.md`をコピーした`.yomiyasu/voice-card.md`が、ボイスカードの置き場所です。自分で書いた文章を3〜5本渡して「この文章からボイスカードを作って」と頼むと、yomiyasuが項目を埋めた案を出します。
