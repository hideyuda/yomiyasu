# 硬さ辞書（公用文や翻訳調の言い回しを、ふだんの言い方に開く）

`slop-catalog.md`はAI特有の不自然な比喩や装飾を扱う。本辞書は、それとは別の「用途に合わない硬さ」を扱う。

比喩動詞を直接的な言葉に直すと、置き換え先が公用文や仕様書の言い回しになりやすい。たとえば「調査に丸一日溶かした」を「調査に丸一日を要しました」と直すと、比喩は消えるが、チャットやSNSでは人が書いた文に見えない。一方で、官公庁の文書や仕様書では「〜において」「発生する」がふつうに使われ、人が書いた文でも多く出てくる。硬さは人かAIかを見分ける目印ではなく、行き先に合っているかどうかの問題である。

そのため本辞書は、用途プロファイル（`references/profiles/`）が決めた「開く強さ」に従って使い、プロファイルがないときは使わない。

- 強さ1（提案資料）: 「〜することが可能です」「〜を行う」のような、同じ意味をもっと短く言える形だけを直す。漢語は短く正確なら残す。
- 強さ2（Web記事、社外向けチャット）: 強さ1に加え、和語で同じ意味を言える漢語を開く。
- 強さ3（SNS、社内向けチャット）: 強さ2に加え、話し言葉に近い言い方にする。

どの強さでも、SKILL.mdの「意味の保持」を優先する。また、強さ1でも、SKILL.md 1章の「『発生』『担保』のような硬い2字漢語を不要な場面で連発しない」決まりは守る。専門用語（冪等性、指数バックオフなど）、固有名詞、法律や契約の用語は開かない。言い切りの強さ（断定・推量・可能性）は変えない。

---

## 1. 短く言える述語（強さ1から）

| 硬い言い方 | ふだんの言い方 | 補足 |
|---|---|---|
| 〜することが可能です | 〜できます | |
| 〜を行う（確認を行う、対応を行う） | 〜する（確認する、対応する） | |
| 〜という形になります | 〜します / 〜です | |
| 〜ということになります | 〜です | |
| 〜の次第です | 〜です | |
| 〜でございます | 〜です | 社外の改まった文書では残す |
| 〜させていただきます（2回目以降） | 〜します | 相手の許可をもらう場面（「欠席させていただきます」）は残す |
| 〜いただけますと幸いです（2回目以降） | 〜をお願いします / 〜してください | 1回なら残してよい |

## 2. 和語で言える漢語・ビジネス語（強さ2から）

| 硬い言い方 | ふだんの言い方 | 補足 |
|---|---|---|
| 〜において | 〜で | |
| 〜に関して | 〜について | |
| 〜を要する | 〜がかかる / 〜が要る | |
| 発生する（不具合、エラー） | 起きる / 出る | |
| 迅速に | すぐに / 早めに | |
| 円滑に | スムーズに / 問題なく | |
| 担保する | 守る / 確保する / 保証する | 「担保」が契約上の担保を指すときは残す |
| 〜に資する / 〜に寄与する | 〜に役立つ | |
| 〜の観点から | 〜から見ると / 〜を考えると | |
| 活用する | 使う | |
| 推進する | 進める | |
| 不可欠です | 欠かせません / 必要です | |
| 〜を図る | 〜する | 「効率化を図る」なら、元の文から分かる範囲で何をするかを書く |
| 〜が可能です | 〜できます | |
| 〜となります（「です」の言い換え） | 〜です | 変化を表す「〜となる」（「来月から有料となります」）は残す |

辞書にない漢語（「契機」「時期」「要因」など）は、和語に置き換えても長さがほとんど変わらず、意味の幅も同じときだけ開く（契機 → きっかけ、時期 → ころ）。置き換えると長く回りくどくなる語や、ほかに言い方のない語（属人化、責任者など）は残す。

## 3. 話し言葉に近い言い方（強さ3のみ）

| 書き言葉 | 話し言葉に近い言い方 | 補足 |
|---|---|---|
| したがって / そのため | なので | 文頭の「なので」は話し言葉寄りなので、上長や社外が読む文では「そのため」のまま |
| すなわち | つまり | |
| ならびに / および | と | 並べる語が2つのとき |
| 〜と考えております | 〜と思っています | |
| 〜のほどよろしくお願いいたします | 〜をお願いします | 社外向けでは残す |
| 〜のため、 | 〜ので、 | 理由を表すとき |
| しかし、 | ただ、 | 逆接が弱いとき。強い逆接は「でも」「しかし」のまま |

## 4. 構文の硬さ

語の置き換えでは直らない硬さもある。

- 同じ主語のくり返し。「インフラチームは〜します。インフラチームは〜します。」のように、近くの文で同じ主語が続くと翻訳調になる。初めて出たところで誰が動くかが分かれば、2回目以降は省いても通じる（SKILL.md「主語は足しません」と同じ考え方）。
- サ変名詞の連なり。「障害発生時の原因究明の迅速化」は「障害が起きたときに、原因をすぐ調べられるようにする」のように動詞に開く。
- 「〜こと」で終わる名詞化。「確認することが必要です」は「確認が必要です」とする。文の働き（説明か依頼か）は変えない。
- 文頭のつなぎ言葉の連続。「また、」「さらに、」「加えて、」が続くときは、前後の関係がただの並列なら削る。
- 体言止めの連続（資料以外）。記事やチャットで体言止めが3つ以上続くと、報告書の箇条書きのように見える。

## 5. 開きすぎない

- 提案資料では「〜の削減」「〜の短縮」のような名詞止めを資料の書き方として残す（`profiles/proposal.md`）。
- 敬語の段階は相手との関係で決まる。社外向けのメールやチャットで「いたします」を「します」に下げない。
- 開いた結果、元の語より長く回りくどくなるときは開かない。
- 読み手が知らないかもしれない専門用語でも、本文に説明を勝手に足さない。必要なら「書き手に確かめたい点」に出す。
